# Connectify 🚀

Connectify is a full-stack MERN social media web application where users can create posts, like posts, comment on posts, and manage their profile.

Built with:
- MongoDB
- Express.js
- React.js
- Node.js
- Tailwind CSS
- JWT Authentication

---

# ✨ Features

## 🔐 Authentication
- User Registration
- User Login
- JWT Authentication
- Protected Routes
- Persistent Login

---

## 📝 Posts
- Create Post
- Edit Post
- Delete Post
- View All Posts

---

## ❤️ Social Features
- Like / Unlike Posts
- Add Comments

## 👤 User Profile

# ⚙️ Environment Variables

## Backend `.env`

Create a `.env` file inside `backend/`

```env
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
PORT=5000
```

# 🚀 Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/SanjivKumarPatel/connectify.git
```

---

## 2️⃣ Install Backend Dependencies

```bash
cd backend
npm install
```

---

## 3️⃣ Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

---

# ▶️ Run Project

## Start Backend

```bash
cd backend
npm run dev
```

---

## Start Frontend

```bash
cd frontend
npm run dev
```
